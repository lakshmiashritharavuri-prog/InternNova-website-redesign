# InternNova Website Redesign 🚀

## About the Project
This project is a redesign of the InternNova website.
The goal is to create a modern, professional and
user-friendly website.

## Objective
To improve the user interface and user experience
while maintaining the InternNova brand identity.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Responsive Navigation Bar
- Hero Section
- About InternNova
- Internship Programs
- Internship Domains
- Why Choose InternNova
- Learning and Mentorship
- Workshops
- Student Testimonials
- FAQ Section
- Contact Section
- Responsive Design for Mobile and Desktop

## Project Purpose
This project is developed as part of a Web Development
internship activity.
